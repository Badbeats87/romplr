                    PORTING LINUX ROMPLER TO BARE-METAL
                              Quick Summary
═══════════════════════════════════════════════════════════════════════════════

THE PROBLEM
───────────
The Linux version (rompler-linux/main.c) is complete and working.
The bare-metal version (rompler/kernel.cpp) is stuck debugging USB MIDI.

THE SOLUTION
────────────
Extract the synth engine from Linux and port it to bare-metal Circle.

WHY THIS WORKS
──────────────
✓ Linux main.c is 1732 lines:
  - ~1200 LOC pure DSP (portable C)
  - ~500 LOC OS-specific (replaceable with Circle APIs)

✓ Circle has everything we need:
  - PWM audio output (already working at 48kHz)
  - USB MIDI support (being debugged)
  - FAT32 filesystem access (via FATFS)
  - Spinlocks for synchronization

KEY APIS TO REPLACE
────────────────────
Audio:         snd_pcm_open/writei    →  CPWMSoundBaseDevice::GetChunk()
MIDI:          pthread_create/read    →  CUSBMIDIDevice callback + queue
File I/O:      fopen/fread/closedir   →  FATFS f_open/f_read/f_readdir
Synchronization: pthread_mutex_*      →  CSpinLock::Acquire/Release()

QUICK START (Omit MIDI for now)
────────────────────────────────
To get audio working without MIDI:

1. Extract synth core to synth/shared/
   └─ Modular: voice.c, envelope.c, filter.c, lfo.c, effects.c

2. Implement CSynthSound in kernel.cpp
   └─ Replace CTestSound, implement GetChunk() callback

3. Load samples from SD at boot
   └─ Use FATFS to read WAV files, populate sample banks

4. Build and test
   └─ Should hear synth output on audio out

5. Wait for USB MIDI fix, then add MIDI input

RISKS & MITIGATIONS
────────────────────
Risk 1: USB MIDI still broken
└─ Mitigation: Debug first (see STATUS.md). Get audio working first.

Risk 2: Audio dropout (GetChunk() too slow)
└─ Mitigation: Keep GetChunk() <10ms. Profile with Circle tools.

Risk 3: Sample rate mismatch (44.1kHz → 48kHz)
└─ Mitigation: Resample or regenerate sample data.

Risk 4: Memory too tight
└─ Mitigation: Pi 4 has 8GB. Current needs: ~32MB samples + ~5MB synth = OK.

SUCCESS CRITERIA
─────────────────
✓ Synth renders at 48kHz stereo via PWM
✓ Samples load from SD card at boot
✓ MIDI input works (after USB fix)
✓ Chorus + reverb effects audible
✓ No crashes in 1+ hour runtime
